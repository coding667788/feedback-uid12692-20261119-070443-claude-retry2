实现离线合规删除计划器。每个请求固定发生时刻和录入截点，只有录入序号不超截点的规则、记录事实、保全与解除可见。记录所属法域采用双时间版本，按发生时有效且截点可见的最新修订，明确同版异值何时拒绝。各法域规则独立计算最早可删及最晚必须删，以 UTC 整日秒数运算；有效保全禁止删除但仍报告逾期，保全解除可追溯并须引用确切保全 ID。

以合成的原件与派生副本构成依赖 DAG。先删下游才可删上游，每日同批次允许依赖按拓扑先后消除；给定最多 16 个待删对象、未来至多 7 个 UTC 日及逐日容量，在所有合法计划中最大化按期删除数，再最小化实际删除日序号之和，再按日、依赖可行的对象 ID 选字典序最小计划。过期且可删对象仍可排入计划。输出阻断路径及审计截点，核对补录保全改写当前判断却不改变历史回放、紧期限原件受下游阻断、日容量导致贪心失优，以及规则时间恰相等。

允许历史查询带任意已记录的录入截点。已逾期对象的删除不计入按期数；以不删除为其最后字典序选项。容量按每对象占一单位。展示必须删除、可选清理和规则矛盾三种不同情形。

在 Windows 原生 Python 3.12 上完成，仅用标准库和 CPU。所有输入自行合成，在本地测试目录离线运行。交付源码、README、可重放的 cases.json、自动化测试。统一提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v，README 写明输入结构、错误码、边界示例和实测结果。预期值须由独立判定或明确断言得出，测试不得从被测实现反推期望结果。
